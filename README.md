# marvel-engine

Motor de producción de contenido para el canal Marvel/cinematográfico.

## Comando principal

### `vamos a grabar un vídeo`

Activa el flujo completo de producción de un vídeo individual.

El motor debe:

1. Investigar tendencias y oportunidades actuales.
2. Verificar los datos con fuentes primarias cuando sea posible.
3. Elegir el ángulo con mayor potencial de curiosidad y retención.
4. Crear 2-3 hooks y seleccionar el más fuerte.
5. Generar el guion corto.
6. Diseñar el plan de aparición del creador y B-roll.
7. Preparar las instrucciones de edición para CapCut.
8. Definir sonido, captions y recursos visuales.
9. Crear descripción y hashtags.
10. Entregar fuentes y comprobación de hechos.
11. Terminar con una checklist de grabación.

El comando crea un paquete de producción para un único vídeo. No presupone un calendario de 15 o 30 días.

La especificación completa del comando está en [commands/vamos-a-grabar-un-video.md](commands/vamos-a-grabar-un-video.md).
